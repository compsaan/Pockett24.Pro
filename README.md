# Pocket24 PWA
ارفع محتويات هذا المجلد كاملة إلى جذر GitHub Pages (index.html, manifest.webmanifest, sw.js, الأيقونات).
- أندرويد Chrome: افتح الرابط → قائمة ⋮ → «تثبيت التطبيق» — سيثبت كتطبيق حقيقي (WebAPK) بأيقونة P24.
- iOS Safari: زر المشاركة → «إضافة إلى الشاشة الرئيسية».
- وضع العرض: fullscreen — بدون أي شريط متصفح.
